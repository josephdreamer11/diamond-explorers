# 다이아몬드 탐험대

초등학생을 위한 1~2인 다이아몬드 찾기 게임입니다. 땅을 파고, 수학 문제(2학년 덧셈·뺄셈, 1~10단 곱셈)를 풀어 다이아몬드를 모으고, 장비와 펫을 사서 몬스터와 싸워요.

**바로 하기:** https://josephdreamer11.github.io/diamond-explorers/

## 조작

| | 이동 | 파기·공격 | 줍기 | 바꾸기 | 물약 | 상점 |
|---|---|---|---|---|---|---|
| 혼자 | 방향키 | Space | Shift | Q | R | B |
| 1P | WASD | Space | 왼쪽 Shift | Q | R | E |
| 2P | 방향키 | Enter | P | O | K | L |

가방은 `I`. 저장은 오른쪽 위 저장 버튼(저장 칸 3개 + 파일로 내보내기).

`index.html` 하나로 된 게임이라 내려받아서 브라우저로 열어도 됩니다.
